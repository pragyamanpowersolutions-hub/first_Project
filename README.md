# Manpower / Staffing Company Website — Client Review Prototype

This is a responsive, frontend-only concept for a manpower, recruitment and workforce solutions company based in Vikaspuri, New Delhi.

## Important prototype boundaries

- `WORKFORCE PARTNER` is a temporary concept label, not the company's confirmed name.
- The service descriptions and process are draft wording to review with the client.
- The location is shown only as “Vikaspuri, New Delhi, India”; confirm the exact public address before publishing.
- The contact form is a visual demonstration. It does not send, transmit, store, or log the form content.
- There is no backend, database, authentication, resume upload, analytics, production domain or SEO verification configured.
- Do not publish this unchanged. Replace placeholders and obtain the client's approval before launch.

## Run locally on Windows (PowerShell)

1. Extract this folder somewhere convenient, such as your Desktop or a project folder.
2. Open PowerShell in the `manpower-website-prototype` folder.
3. Run:

   ```powershell
   py -m http.server 5500
   ```

4. Open `http://localhost:5500` in Chrome or Edge.
5. To stop the local server, return to PowerShell and press `Ctrl+C`.

If `py` is not available but Python is installed, try:

```powershell
python -m http.server 5500
```

You can also open `index.html` directly, but using the local HTTP server is better for a consistent preview.

## Files

- `index.html` — page structure and draft copy
- `styles.css` — responsive styling and design system
- `script.js` — mobile navigation and demo form feedback

## Suggested client review agenda

1. Does this visual direction feel right for the company and its industry?
2. Is the tone appropriately professional, credible and approachable?
3. Which services does the company actually provide, and which are inaccurate or missing?
4. Should the homepage speak first to employers, candidates, or both equally?
5. What verified credentials, sectors, locations, and differentiators may be published?
6. Which contact details and enquiry-handling process should be used?
7. Are international services direct recruitment, overseas placement, or another model that needs more careful wording?

## Before production

Confirm company name/brand assets, actual service scope, client permissions for any logos or testimonials, copy, legal and privacy needs, contact routing, domain ownership, hosting plan, accessibility, browser/device testing, analytics choices, backups, monitoring and maintenance responsibility. Do not collect real candidate data until the backend/service, access controls, retention plan and privacy notices have been reviewed.
